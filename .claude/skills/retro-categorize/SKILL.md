# Retro 便利貼分類

將從 RetroFinder 復盤頁「複製（含編號）」匯出的便利貼，分類到指定模板的各個區塊，輸出格式可直接貼回 app 的「匯入分類結果」欄位。

## 觸發方式

```
/retro-categorize
```

接著使用者會貼上便利貼內容（含 `[0]`、`[1]`… 編號）。若使用者未指定模板，詢問使用哪個模板。

## 輸入格式

從 RetroFinder 復盤頁點「複製（含編號）」後貼上，格式為：

```
[0] by EJ 即時同步

[1] Kurt 網格的流程目前還是有些地方不清楚

[2] Beverly retro 好像可以隨時寫
...
```

## 輸出格式

每行一筆，**直接可貼入 app**：

```
0: 2
1: 0
2: 4
```

`-1` 代表未分類（保留在未分類區）。

## 分類原則

1. **以整張便利貼的主要情緒 / 目的判斷**，不因其中一句負面就全部歸負面
2. **感謝、稱讚、成功、里程碑 → 太陽（或各模板對應的正向區塊）**
3. **不清楚、卡住、花很多時間、重複討論、沒人確認 → 沼澤 / 阻礙類**
4. **「想要做」「建議」「下次試試」→ 青蛙卵 / 指南針類（嘗試新事物）**
5. **「要繼續做」「保持這樣」「順暢運作」→ 荷葉 / 攀登類（繼續保持）**
6. **需要別人幫忙、需要資源 → 小青蛙 / 阻礙類**
7. **同一張便利貼有多人署名但主題一致，以主題判斷；主題衝突，以篇幅較長者為主**
8. **無法判斷時輸出 `-1`（未分類），不硬塞**

## 輸出規範

- 僅輸出 `noteIndex: areaIndex` 清單，不加說明文字
- 每個便利貼都必須出現一次
- 若有明顯無法歸類者，輸出 `N: -1` 並在清單後附一行說明
- 輸出完後提示使用者：「複製以上內容，貼到復盤頁的『匯入分類結果』欄位，點套用即可。」
